## Как открыть

1. Открыть https://app.diagrams.net/ .
2. Выбрать работу с файлами на устройстве.
3. Выполнить «Файл – Открыть с устройства» и выбрать общий файл `.drawio`.
4. Переключать вкладки снизу. Для обзора использовать «Вписать страницу».
5. Для редактирования текста дважды нажать на подпись. Классы состоят из редактируемых секций.

Файлы содержат фигуры и соединители, а не встроенные растровые изображения.
Связи с конечными объектами прикреплены к фигурам, где это применимо; линии жизни и маршрутные точки последовательностей заданы координатами.

## Согласование с проектом

Структура классов соответствует 13 таблицам `sibka_pdm_v2`.
Диаграмма состояний соответствует семи переходам триггера `orders_before_update`.
Диагностика пороговая. Модель прогнозирования, API и обмен с 1С являются проектируемыми компонентами.
Функции IDEF0 согласованы по материалам «Мое все методы и уд.docx», раздел IDEF0, страницы 45–51.
Отдельный исходник RAMUS не включён в комплект.

В отчёте текст задан Times New Roman 14, межстрочный интервал 1,5, интервалы до и после абзацев 0.
Отчёт выполнен на листах A4. Диаграммы размещены в соответствующих разделах и сопровождаются описаниями. Пояснения к нотации вынесены в текст; линии связей упрощены.
