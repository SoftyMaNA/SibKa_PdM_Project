# SibKa PdM 0.8.0

## Требования

macOS 15 или новее. Для Apple M1/M2/M3/M4 и новее выберите arm64, для Intel – x86_64. Архитектура проверяется в меню Apple → Об этом Mac. Python и pip для запуска установленной версии не требуются: интерпретатор и библиотеки включены в пакет. MySQL/MariaDB запускается отдельно, например через XAMPP. Веб-сервер Apache для этого приложения не требуется; он нужен для phpMyAdmin.

## Установка

1. Скачайте подходящий .pkg со страницы выпуска v0.8.0 в GitHub.
2. Откройте пакет в системном «Установщике», последовательно выберите «Продолжить» и «Установить». Для записи в /Applications потребуется пароль администратора.
3. Пакет собран без сертификата Apple Developer и не нотарифицирован. Если macOS блокирует его, используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» только для скачанного выпуска этого репозитория. Отключать защиту системы не требуется.
4. Откройте /Applications/SibKa PdM/Start SibKa PdM.command.
5. При первом запуске создаётся ~/Library/Application Support/SibKa PdM/config.local.json. Начальные параметры: 127.0.0.1, 3306, root, пустой пароль, sibka_pdm_v2.
6. Если у вашей MariaDB другие параметры, остановите сервер Ctrl+C, откройте JSON в текстовом редакторе, измените значения и запустите приложение снова. Не размещайте файл с паролем в GitHub.
7. Включите MySQL в XAMPP. В браузере откроется http://127.0.0.1:5001. Сервер работает, пока открыто окно запуска. Остановка – Ctrl+C.

## База данных

Если sibka_pdm_v2 уже заполнена, повторный импорт НЕ нужен. Установщик не выполняет SQL и не подключается к MySQL. Файл /Applications/SibKa PdM/database/SibKa_PdM_v2.sql предназначен только для нового развёртывания. Дамп создаёт новую схему и останавливается, если база уже существует. Перед любыми изменениями существующей базы сделайте резервную копию; не удаляйте её для повторного импорта. Проверочные запросы Lab7_connection_checks.sql только читают данные.

## Проверка установки

В Терминале выполните:

    "/Applications/SibKa PdM/runtime/sibka-pdm" --version
    "/Applications/SibKa PdM/runtime/sibka-pdm" --self-test
    pkgutil --pkg-info ru.sibka.pdm

Самопроверка загружает Flask, шаблоны и CSS, проверяет два пороговых значения. Она не проверяет подключение к вашей БД. После запуска откройте обзор парка, карточку техники и список заявок. Для проверки сохранения создайте заявку на узел с отклонением, затем найдите её по номеру.

Для подтверждения лабораторной сохраните снимки: окна установки, сообщения об успешной установке, папки установленного приложения, результата --self-test и работающего приложения.

## Обновление и удаление

Перед обновлением остановите приложение. Новая установка заменяет файлы в /Applications/SibKa PdM. Пользовательская конфигурация хранится отдельно и сохраняется. База MySQL не изменяется.

Для удаления остановите сервер и переместите папку /Applications/SibKa PdM в Корзину через Finder с подтверждением администратора. Пользовательские настройки можно удалить отдельно из ~/Library/Application Support/SibKa PdM. Базу данных и XAMPP удалять не нужно. Квитанция пакета может остаться в macOS; удалить только запись о пакете можно командой sudo pkgutil --forget ru.sibka.pdm после удаления папки.
