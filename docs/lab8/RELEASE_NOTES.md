Установочные пакеты SibKa PdM для macOS 15 и новее.

- arm64: Mac с Apple Silicon.
- x86_64: Mac с Intel.
- Python, Flask и PyMySQL включены в установку.
- MySQL/MariaDB запускается отдельно. Уже заполненная sibka_pdm_v2 сохраняется: установщик не выполняет SQL.
- Первый запуск: /Applications/SibKa PdM/Start SibKa PdM.command.
- Инструкция: INSTALL_RU.md; контрольные суммы: SHA256SUMS.txt.
- Пакеты не подписаны сертификатом Apple Developer и не нотарифицированы.

Обе архитектуры проверяются автоматической установкой штатным installer, загрузкой упакованного приложения, шаблонов и CSS и запросами HTTP. Проверка с существующей рабочей БД выполняется после установки на пользовательском компьютере. SQL предназначен только для первого развёртывания и останавливается, если схема уже существует.
